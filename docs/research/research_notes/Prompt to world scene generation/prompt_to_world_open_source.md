# Open-Source / Research "Prompt-to-World" Systems (text or single image -> explorable 3D worlds)

Notes compiled 2026-11-01. Star counts are exact `stargazerCount` values scraped from each GitHub repo page on 2026-11-01 (the GitHub API was rate-limited, so the HTML pages were read directly). Each repo link is the source for its star count and one-line description. arXiv IDs marked † were not re-fetched this session. They come from prior knowledge and the report writer should spot-check them. IDs without † were confirmed in this session's fetches or searches.

## Which open repos generate explorable 3D scenes/worlds from text? (Catalog grouped by approach)

### Takeaway
The field has moved through three phases. (1) 2023–24: per-scene optimization via iterative inpainting plus depth (Text2Room, SceneScape, LucidDreamer, WonderJourney, Text2NeRF) and panorama lifting (DreamScene360, HoloDreamer, LayerPano3D). (2) 2025: industrial-scale open releases that lift a panorama or video into a mesh or 3DGS (HunyuanWorld 1.0, Voyager, Matrix-3D, Lyra, FlashWorld, WorldGrow). (3) 2026: multi-stage "world model" pipelines that combine panorama generation, trajectory planning, video/stereo expansion and 3DGS reconstruction (HY-World 2.0, Lyra 2.0, ABot-3DWorld 0), plus LLM-agentic procedural builders (WorldClaw, Meta WorldGen). A separate branch of "video world models" (Matrix-Game, Yume, HY-World 1.5/WorldPlay) gives interactive navigation without an explicit 3D asset.

### Cited Findings

#### A. Iterative inpainting / outpainting with depth (warp-and-inpaint), 2023–2025
- **Text2Room** (Höllein et al., TUM; ICCV 2023; arXiv 2303.11989†). Text -> textured 3D room **mesh**, built by repeatedly generating images with a 2D text-to-image model, estimating depth and fusing the results. Code released. **1,094 stars.** Limitations: indoor rooms only, and per-scene optimization is slow. — [GitHub lukasHoel/text2room](https://github.com/lukasHoel/text2room)
- **SceneScape** (Fridman et al., Weizmann; NeurIPS 2023; arXiv 2302.01133†). Text -> perpetual "fly-through" video with an underlying unified **mesh**. Official PyTorch code released. **161 stars.** Limitations: forward camera motion only. — [GitHub RafailFridman/SceneScape](https://github.com/RafailFridman/SceneScape)
- **Text2NeRF** (Zhang et al.; TVCG 2024; arXiv 2305.11588†). Text -> **NeRF** scene via diffusion inpainting and depth. Code released. **138 stars.** — [GitHub eckertzhang/Text2NeRF](https://github.com/eckertzhang/Text2NeRF)
- **LucidDreamer** (Chung et al., SNU; arXiv 2311.13384†; listed as TVCG 2025). "Domain-free generation of **3D Gaussian Splatting** scenes" from text or an image. Code released. **1,528 stars**, the most-starred of the 2023-era inpainting methods. — [GitHub luciddreamer-cvlab/LucidDreamer](https://github.com/luciddreamer-cvlab/LucidDreamer); [Awesome-3D-Scene-Generation](https://github.com/hzxie/Awesome-3D-Scene-Generation)
- **RealmDreamer** (3DV 2025; arXiv 2404.07199†). Text-driven 3D scene generation with inpainting and depth diffusion (3DGS). **302 stars.** — [GitHub jaidevshriram/realmdreamer](https://github.com/jaidevshriram/realmdreamer)
- **WonderJourney** (Yu et al., Stanford/Google; CVPR 2024; arXiv 2312.03884†). Text or image -> a "journey" through a chain of diverse connected 3D scenes, using an LLM to generate scene descriptions. Code released. **772 stars.** — [GitHub KovenYu/WonderJourney](https://github.com/KovenYu/WonderJourney)
- **WonderWorld** (Yu et al.; CVPR 2025; arXiv 2406.09394†). Single image -> interactive, user-guided world expansion with fast per-scene generation (FLAGS, layered Gaussian surfels). Code released. **746 stars.** — [GitHub KovenYu/WonderWorld](https://github.com/KovenYu/WonderWorld); [Awesome list](https://github.com/hzxie/Awesome-3D-Scene-Generation)
- **WonderPlay** (ICCV 2025 Highlight; arXiv 2505.18151†). Dynamic 3D scene generation from a single image plus actions (physics plus video hybrid). **39 stars.** — [GitHub kyleleey/WonderPlay](https://github.com/kyleleey/WonderPlay)
- **Other Wonder\* follow-ups** (2025–26): WonderTurbo (ICCV 2025, **49 stars**, [GitHub](https://github.com/GigaAI-research/WonderTurbo)), WonderFree (**19 stars**, [GitHub](https://github.com/GigaAI-research/WonderFree)), WonderZoom (2025) and PerpetualWonder (CVPR 2026). — [Awesome list](https://github.com/hzxie/Awesome-3D-Scene-Generation)
- **Other open iterative methods listed in the survey repo:** Invisible Stitch (3DV 2025), BloomScene (AAAI 2025), ScenePainter (ICCV 2025), Scene123 (MM 2025), EvoScene ("Self-Evolving 3D Scene Generation from a Single Image", CVPR 2026, **29 stars**, [GitHub](https://github.com/UCSB-AI/EvoScene)) and SceneFrom3D (2026). — [Awesome-3D-Scene-Generation](https://github.com/hzxie/Awesome-3D-Scene-Generation)
- **SynCity** (Engstler et al., Oxford; ICCV 2025; arXiv 2503.16420†). Training-free generation of 3D worlds from text. It grows a grid of tiles by combining 2D image generation with an image-to-3D model (TRELLIS). **679 stars.** A follow-up, SynCity 3000, is listed for ECCV. — [GitHub paulengstler/syncity](https://github.com/paulengstler/syncity); [Awesome list](https://github.com/hzxie/Awesome-3D-Scene-Generation)

#### B. Panorama-lifting (generate a 360° panorama, then lift to 3D)
- **DreamScene360** (Zhou et al., UCLA; ECCV 2024; arXiv 2404.06903†). "Unconstrained text-to-3D scene generation with panoramic **Gaussian splatting**." **133 stars.** — [GitHub ShijieZhou-UCLA/DreamScene360](https://github.com/ShijieZhou-UCLA/DreamScene360)
- **HoloDreamer** (arXiv 2407.15187†; listed as TVCG 2026). "Holistic 3D panoramic world generation from text descriptions" (3DGS). **64 stars.** — [GitHub zhouhyOcean/HoloDreamer](https://github.com/zhouhyOcean/HoloDreamer)
- **LayerPano3D** (3DTopia / Shanghai AI Lab; SIGGRAPH 2025; arXiv 2408.13252†). Layered 3D panorama for "hyper-immersive" scene generation, which decomposes the panorama into depth layers to handle occlusion. **326 stars.** — [GitHub 3DTopia/LayerPano3D](https://github.com/3DTopia/LayerPano3D)
- **DreamCube** (ICCV 2025). 3D panorama generation via multi-plane synchronization. **182 stars.** — [GitHub Yukun-Huang/DreamCube](https://github.com/Yukun-Huang/DreamCube)
- **OmniX** (HKU MMLab; listed ECCV 2026). "Unified panoramic generation and perception to **graphics-ready 3D scenes**." **115 stars.** — [GitHub HKU-MMLab/OmniX](https://github.com/HKU-MMLab/OmniX)
- **WorldGen (Ziyang Xie; open-source tool, not the Meta paper).** Text, image or 360° panorama -> **3DGS (.ply) or mesh**. The pipeline uses FLUX.1-dev, DA-2 360° depth (which replaced UniK3D in April 2026), Apple ml-sharp, OneFormer and LaMa, with a Viser viewer. The project was open-sourced 2025-04-21, is at v0.2.0 (April 2026), uses Apache-2.0, needs about 10 GB VRAM in low-VRAM mode, and claims "seconds" per scene. **2,186 stars.** Limitations: setup is involved, ml-sharp and inpainting are experimental, and no tech report has been released. — [GitHub ZiYang-xie/WorldGen](https://github.com/ZiYang-xie/WorldGen)
- **HunyuanWorld 1.0** (Tencent Hunyuan; released 2025-07-26; arXiv 2507.21809†). Text or image -> 360° panorama as a "world proxy" -> **semantically layered 3D mesh** with separable foreground objects, exportable with Draco compression. It is built on FLUX. Weights on Hugging Face: PanoDiT-Text, PanoDiT-Image, PanoInpaint-Scene and PanoInpaint-Sky. A quantized "lite" version (2025-08-15) runs on a 4090. **2,958 stars.** Limitations: some scenes fail to load in the viewer and setup is heavy. — [GitHub Tencent-Hunyuan/HunyuanWorld-1.0](https://github.com/Tencent-Hunyuan/HunyuanWorld-1.0)
  - License caveat: commentary describes the license as closer to "source available" than open source, with geographic and user restrictions. — [The Neuron](https://www.theneuron.ai/explainer-articles/tencent-just-open-sourced-a-3d-world-generator)
- **Other panorama/holistic entries, 2025–26:** CubeDiff (ICLR 2025), "A Recipe for Generating 3D Worlds From a Single Image" (ICCV 2025), ImmerseGen (TVCG 2026), GuidedSceneGen (ECCV 2026), One2Scene (ICLR 2026, **56 stars**, [GitHub](https://github.com/Wang-pengfei/One2Scene)), CGGS (TIP 2026), RoamScene3D, WorldComposer (**23 stars**), PixWorld and EvoWorld ("Evolving Panoramic World Generation with Explicit 3D Memory", **77 stars**, [GitHub](https://github.com/JiahaoPlus/EvoWorld)). — [Awesome-3D-Scene-Generation](https://github.com/hzxie/Awesome-3D-Scene-Generation)

#### C. Feed-forward / native 3D-latent Gaussian-splat and mesh world generators
- **Director3D** (Li et al.; NeurIPS 2024; arXiv 2406.17601†). Text -> real-world camera trajectory plus **3DGS** scene. **382 stars.** — [GitHub imlixinyang/Director3D](https://github.com/imlixinyang/Director3D)
- **FlashWorld** (Xinyang Li et al.; ICLR 2026 Oral; arXiv 2510.13678†). "High-quality 3D scene generation within seconds": it outputs **3DGS** directly in 5–10 s on a single GPU, and Tencent's HunyuanWorld README lists it as part of its family. **871 stars.** — [GitHub imlixinyang/FlashWorld](https://github.com/imlixinyang/FlashWorld); [HunyuanWorld-1.0 README](https://github.com/Tencent-Hunyuan/HunyuanWorld-1.0)
- **Prometheus** (CVPR 2025; arXiv 2412.21117†). A 3D-aware latent diffusion model for feed-forward text-to-3D scene generation (3DGS). **149 stars.** — [GitHub XDimLab/Prometheus](https://github.com/XDimLab/Prometheus)
- **VideoRFSplat** (ICCV 2025). Text-to-3DGS scene generation. — [Awesome list](https://github.com/hzxie/Awesome-3D-Scene-Generation)
- **BlockFusion** (SIGGRAPH 2024; arXiv 2401.17053†). Expandable 3D scene generation using latent tri-plane extrapolation. The repo page could not be scraped at the URL tried (yangcaoai/BlockFusion), so the star count is unknown. — Gap
- **LT3SD** (Meng et al.; CVPR 2025; arXiv 2409.08215†). A latent 3D scene diffusion model for "infinite 3D environments" (geometry). **199 stars.** — [GitHub quan-meng/lt3sd](https://github.com/quan-meng/lt3sd)
- **NuiScene** (ICCV 2025). Efficient generation of unbounded outdoor scenes. — [Awesome list](https://github.com/hzxie/Awesome-3D-Scene-Generation)
- **WorldGrow** (Sikuang Li et al., SJTU / Huawei / HUST; AAAI 2026 Oral; arXiv 2510.21682). It grows infinite 3D worlds block by block from a seed block, using coarse-to-fine refinement built on TRELLIS. Outputs are **3DGS .ply, mesh .glb and a video**. Inference code and weights were released 2025-11-14 (HF: UranusITS/WorldGrow). The license is still "TBD". Limitations: the example shown is indoor (a 19x39-block world of about 1,800 m²), it has no text conditioning on the page, and the training code status is unclear. **500 stars.** — [GitHub world-grow/WorldGrow](https://github.com/world-grow/WorldGrow)
- **Roblox Cube** (2025). The "Roblox Foundation Model for 3D Intelligence" (text-to-3D assets, with scene generation as a stated goal). **1,304 stars.** — [GitHub Roblox/cube](https://github.com/Roblox/cube); [Awesome list](https://github.com/hzxie/Awesome-3D-Scene-Generation)

#### D. Video-model-based worlds, two-stage (generate camera-controlled video or RGB-D, then reconstruct explicit 3D)
- **HunyuanWorld-Voyager** (Tencent; 2025-09-02; arXiv 2506.04225†; listed as TOG). "Interactive RGBD video generation model conditioned on camera input" that supports real-time 3D reconstruction (point cloud / 3DGS). **1,603 stars.** — [GitHub Tencent-Hunyuan/HunyuanWorld-Voyager](https://github.com/Tencent-Hunyuan/HunyuanWorld-Voyager); [HunyuanWorld README](https://github.com/Tencent-Hunyuan/HunyuanWorld-1.0)
- **Matrix-3D** (Skywork AI; open-sourced 2025-08-12; arXiv 2508.08086). Single image or text -> panorama video (conditional video generation) -> panoramic 3D reconstruction, producing "omnidirectional explorable 3D worlds". It has a one-command `generate.sh`, a 19 GB VRAM script, and a 5B low-VRAM model that needs 12 GB. A Gradio demo followed on 2025-08-29. Tested on Linux with an NVIDIA GPU. **850 stars** (third-party sites quote about 753, an older figure, and an MIT license that was not verified). — [GitHub SkyworkAI/Matrix-3D](https://github.com/SkyworkAI/Matrix-3D); [HF Skywork/Matrix-3D](https://huggingface.co/Skywork/Matrix-3D); [TechNode release](https://technode.global/prnasia/matrix-3d-goes-open-source-a-new-benchmark-for-3d-world-generation/); [Toolify](https://www.toolify.ai/ai-model/skywork-matrix-3d)
- **Lyra 1.0** (NVIDIA Toronto AI Lab; 2025-09-23; arXiv 2509.19296). "Feed-forward 3D and 4D scene generation from a single image/video via video diffusion model self-distillation." Code and weights released (HF nvidia/Lyra). — [GitHub nv-tlabs/lyra](https://github.com/nv-tlabs/lyra)
- **Lyra 2.0** (Tianchang Shen, Sherwin Bahmani, ... Sanja Fidler, Jun Gao, Xuanchi Ren; NVIDIA; arXiv 2604.13036, 2026-04-14; listed as SIGGRAPH Asia 2026). "Explorable generative 3D worlds". It generates long camera-controlled walkthrough videos, then lifts them to 3D with feed-forward reconstruction. It fixes **spatial forgetting** by keeping per-frame 3D geometry to retrieve past frames, and **temporal drift** by training on self-augmented histories. Weights are on HF (nvidia/Lyra-2.0), and the GUI and training code followed on 2026-07-20. Source code is Apache 2.0, with per-model licenses in subfolders. The combined Lyra repo has **2,799 stars**. — [arXiv 2604.13036](https://arxiv.org/abs/2604.13036); [Project page](https://research.nvidia.com/labs/sil/projects/lyra2/); [GitHub nv-tlabs/lyra](https://github.com/nv-tlabs/lyra)
- **GEN3C** (NVIDIA; CVPR 2025 Highlight). 3D-informed, world-consistent video generation with precise camera control, using a point-cloud cache. **1,445 stars.** — [GitHub nv-tlabs/GEN3C](https://github.com/nv-tlabs/GEN3C)
- **DimensionX** (ICCV 2025). Single image -> 3D and 4D scenes via controllable video diffusion. **1,336 stars.** — [GitHub wenqsun/DimensionX](https://github.com/wenqsun/DimensionX)
- **WorldExplorer** (SIGGRAPH Asia 2025). "Towards generating fully navigable 3D scenes" from text (video-based 3DGS). **198 stars.** — [GitHub mschneider456/worldexplorer](https://github.com/mschneider456/worldexplorer)
- **Wonderland** (Snap Research; CVPR 2025). Single image -> 3D scene via a video-latent-to-3DGS feed-forward model. **165 stars.** — [GitHub snap-research/wonderland](https://github.com/snap-research/wonderland)
- **FlexWorld** (2025). Progressively expanding 3D scenes for flexible-view synthesis. **137 stars.** — [GitHub ML-GSAI/FlexWorld](https://github.com/ML-GSAI/FlexWorld)
- **WorldForge / WorldForge v2** (Westlake; CVPR 2026 Highlight). Training-free guidance of video models for 3D/4D trajectories. **183 stars.** — [GitHub Westlake-AGI-Lab/WorldForge](https://github.com/Westlake-AGI-Lab/WorldForge)
- **VMem** (ICCV 2025 Highlight). Consistent interactive video scene generation with surfel-indexed view memory. **451 stars.** — [GitHub runjiali-rl/vmem](https://github.com/runjiali-rl/vmem)
- **HunyuanWorld-Mirror / WorldMirror** (HunyuanWorld 1.1; 2025-10-22; ICML 2026). A fast, universal feed-forward 3D reconstruction model (video or multi-view -> 3D). It is the reconstruction back-end for Tencent's world pipelines. **1,221 stars.** — [GitHub Tencent-Hunyuan/HunyuanWorld-Mirror](https://github.com/Tencent-Hunyuan/HunyuanWorld-Mirror)
- **HY-World 2.0** (Tencent Hunyuan; tech report 2026-04-16; HY-Pano 2.0 code and weights 2026-05-11; full world-generation inference plus WorldStereo 2.0 weights 2026-05-18; an "HY World 2.1" update was announced in July 2026 without details). Text, single image, multi-view or video input -> **3DGS, mesh and point cloud**, importable into Unity, Unreal and Isaac. Components: HY-Pano 2.0 (text/image -> 360° panorama, about 80B parameters, plus a 425M Qwen LoRA variant), WorldNav (VLM-guided, obstacle-aware camera trajectory planning), WorldStereo 2.0 (panorama -> 3DGS world expansion with memory-guided keyframes, about 17B), WorldMirror 2.0 (reconstruction, about 1.2B) and 3DGS composition/training. Released under the "HY-World 2.0 Community License". Tencent claims quality comparable to World Labs' closed Marble. **2,812 stars.** Limitations: very large models, a recommended CUDA 12.8 / Hopper (FA3) stack, and an April article noting the one-click pipeline was not yet fully open (fixed in May). — [GitHub Tencent-Hunyuan/HY-World-2.0](https://github.com/Tencent-Hunyuan/HY-World-2.0); [NYU Shanghai RITS](https://rits.shanghai.nyu.edu/ai/tencent-open-sources-hy-world-2-0-a-multi-modal-3d-world-model/); [Gigazine](https://gigazine.net/gsc_news/en/20260417-tencent-hy-world-2); [Tech report PDF](https://3d-models.hunyuan.tencent.com/world/world2_0/HY_World_2_0.pdf)
- **ABot-3DWorld 0** (Mingchao Sun + 36 co-authors; project page abot-world.amap.com, i.e., AMAP / Alibaba; arXiv 2607.11673, July 2026). Text, image or video -> "Spatial Generative Primitive" (panorama plus point cloud) -> 3D-consistent panoramic video along a planned trajectory -> **3DGS world**, optionally anchored to geographic POIs. It claims SOTA among open-source methods and better fidelity than Marble with rich inputs. **Code/weights release not confirmed.** — [arXiv 2607.11673](https://arxiv.org/html/2607.11673v2)
- **Other two-stage entries:** GenXD (ICLR 2025), StarGen (CVPR 2025), DreamJourney (TMM 2025), Free4D (ICCV 2025), 4DNeX, HoloTime, FantasyWorld (ICLR 2026), Captain Safari (CVPR 2026), WorldReel (CVPR 2026), LivingWorld and OctWorld (ECCV 2026). — [Awesome-3D-Scene-Generation](https://github.com/hzxie/Awesome-3D-Scene-Generation)

#### E. Video world models, one-stage (interactive navigation in pixel space; no explicit 3D asset)
- **Matrix-Game series** (Skywork AI). 1.0 (2025-05-12); 2.0 (2025-08-12, a real-time long-video interactive world model, arXiv 2508.13009†); 3.0 (2026-03-27, real-time streaming with long-horizon memory); **4.0 (2026-10-15)**, "streaming neural rendering": a causal few-step video model sits under a game engine and turns low-poly RGB frames plus text into detailed visuals. It reaches 67 FPS on an RTX 5080 and 58 FPS on an RTX 5070 Ti at 864x480 (steady state, fixed prompts, SageAttention). It is Apache-2.0, with weights for three scenes only (Medieval Castle, Ancient Egypt, City Racing). **2,817 stars.** — [GitHub SkyworkAI/Matrix-Game](https://github.com/SkyworkAI/Matrix-Game)
- **HY-World 1.5 / WorldPlay** (Tencent; 2025-12-18). "A systematic framework for interactive world modeling with real-time latency and geometric consistency." **1,623 stars.** — [GitHub Tencent-Hunyuan/HY-WorldPlay](https://github.com/Tencent-Hunyuan/HY-WorldPlay)
- **Yume** (Xiaofeng Mao, Kaipeng Zhang, Yu Qiao et al., Shanghai AI Lab authorship; Yume 1.0 on 2025-07-23, arXiv 2507.17744; Yume 1.5 / Yume-5B on 2025-12-26, arXiv 2512.22096). Text, image or video -> interactive explorable video world with keyboard camera control. Built on Wan2.1/2.3-era code, with Masked Video DiT training and distillation. Weights are Yume-I2V-540P and Yume-5B-720P under Apache-2.0. Inference needs at least 16 GB VRAM and training needs at least 16 A100s. **685 stars.** — [GitHub stdstu12/YUME](https://github.com/stdstu12/YUME)
- **Other open interactive video world models:** GameFactory (Kuaishou/Kling, ICCV 2025, **501 stars**, [GitHub](https://github.com/KwaiVGI/GameFactory)), MineWorld (Microsoft, **494 stars**, [GitHub](https://github.com/microsoft/MineWorld)), WorldMem (NeurIPS 2025, **401 stars**, [GitHub](https://github.com/xizaoqu/WorldMem)), GenEx (ICLR 2025, **173 stars**, [GitHub](https://github.com/Beckschen/genEx)), DynamicVoyager (ICCV 2025), GameGen-X (ICLR 2025), Hunyuan-GameCraft and MagicWorld. — [Awesome-3D-Scene-Generation](https://github.com/hzxie/Awesome-3D-Scene-Generation)

#### F. Procedural and LLM-agentic generation (programs or engines build the world)
- **Infinigen** (Princeton VL; CVPR 2023; arXiv 2306.09310†) and **Infinigen Indoors** (CVPR 2024; arXiv 2406.11824†). "Infinite photorealistic worlds using procedural generation" in Blender, with no neural generator and fully procedural meshes and materials. **7,372 stars**, the most-starred repo in this catalog. Limitation: random or parameterized sampling rather than free-form text prompting. — [GitHub princeton-vl/infinigen](https://github.com/princeton-vl/infinigen)
- **Holodeck** (AllenAI; CVPR 2024; arXiv 2312.09067†). Language-guided generation of 3D embodied-AI environments: an LLM plans the layout and Objaverse assets are retrieved. **580 stars.** — [GitHub allenai/Holodeck](https://github.com/allenai/Holodeck)
- **WorldGen (Meta Reality Labs)** (Dilin Wang, Andrea Vedaldi + ~23 co-authors; arXiv 2511.16825, 2025-11-20; CVPR 2026). Text -> **traversable, interactive 3D worlds**. An LLM-driven procedural blockout with a navmesh is styled by an image generator, then image-to-3D reconstruction builds the scene, which is decomposed into objects and regenerated at higher resolution. Outputs are separate meshes for game engines. Secondary coverage cites about 5 minutes per world. **No public code found** (a GitHub repo for "facebookresearch/worldgen" could not be resolved). — [arXiv 2511.16825](https://arxiv.org/abs/2511.16825v1); [CVPR 2026 poster](https://cvpr.thecvf.com/virtual/2026/poster/39770); [AI News](https://www.artificialintelligence-news.com/news/worldgen-meta-generative-ai-for-interactive-3d-worlds/)
- **WorldClaw** (Tencent Hunyuan 3D; Chunchao Guo, Jinpeng Li, Yang Li, Zilong Huang; arXiv 2608.05248, 2026-08-05). An agentic coarse-to-fine pipeline. Planning agents turn the prompt into a spec of regions, terrain, assets and materials. It builds a region-aware height-field terrain, generates terrain-conditioned compositions, reconstructs textured meshes and recovers their placement, then render-based agents refine the result. Output: large-scale, explorable, editable **instance-level mesh assets plus terrain**. The arXiv abstract gives no baselines or quantitative scale, but a GitHub repo exists with **1,429 stars**. — [arXiv 2608.05248](https://arxiv.org/abs/2608.05248); [GitHub Tencent-Hunyuan/Hunyuan3D-WorldClaw](https://github.com/Tencent-Hunyuan/Hunyuan3D-WorldClaw)
- **EmbodiedGen** (Horizon Robotics, 2025). "Towards a generative 3D world engine for embodied intelligence." **712 stars.** — [GitHub HorizonRobotics/EmbodiedGen](https://github.com/HorizonRobotics/EmbodiedGen)
- **2026 LLM-based open repos** (from the survey list): 4DSynth, SceneConductor (single image, multi-agent), SceneFoundry ("interactive infinite 3D worlds"), MANSION (multi-floor language-to-3D, AgiBot, **37 stars**), HomeWorld (floorplan-to-whole-home), LandCraft (text-guided landscapes, AAAI 2026), RAISECity (city scale, CVPR 2026) and Text2Villa (project page only). ### Inferences
- **Representations by approach:** 2023 methods produce meshes or NeRF (Text2Room, SceneScape, Text2NeRF). 3DGS has dominated since 2024 (LucidDreamer onward). The 2025–26 industrial pipelines output both 3DGS and meshes (HunyuanWorld 1.0 and HY-World 2.0) because game-engine and robot-simulation import (Unity, UE, Isaac) has become an explicit goal.
- **Convergence:** The "panorama -> trajectory -> video/stereo expansion -> feed-forward reconstruction -> 3DGS" recipe is shared by HY-World 2.0, Matrix-3D, ABot-3DWorld 0 and, in a non-panoramic form, Lyra 2.0. This looks like the de facto 2026 open architecture.
- **Two meanings of "world":** explicit 3D worlds (exportable assets) and interactive video world models (Matrix-Game, Yume, WorldPlay, which render frames but give no persistent geometry). Matrix-Game 4.0 shows a hybrid: an engine supplies the geometry and the video model supplies the appearance.

### Gaps
- BlockFusion's repo URL and stars could not be resolved (yangcaoai/BlockFusion did not return a repo page). The Text2Room-style "Ctrl-Room", "ControlRoom3D", "RoomDreamer", "SceneWiz3D", "DreamScene" (Li et al.), "Scene-LLM" and "GALA3D" were not individually checked.
- License terms of HunyuanWorld 1.0 and HY-World 2.0 were not read in full. Only the "Community License" name and third-party characterization are available.
- Release of code or weights for ABot-3DWorld 0 is unconfirmed. Lyra 2.0's exact output format (3DGS vs. mesh) was not stated on the pages fetched.
- HY World 2.1 (July 2026) has no details beyond an announcement link.
- arXiv IDs marked † are from prior knowledge and were not re-fetched.

## What is the state of the art as of late 2026?

### Takeaway
As of November 2026, the strongest **open** text/image-to-explorable-3D-world systems are Tencent **HY-World 2.0** (a fully open pipeline since May 2026 that outputs 3DGS and meshes, with a claimed Marble-comparable result) and NVIDIA **Lyra 2.0** (long-horizon, 3D-consistent video-to-3D, with weights and training code released). Close behind are **Matrix-3D** and **ABot-3DWorld 0**, which claims open-source SOTA but has unconfirmed code. **FlashWorld** leads on speed (seconds). **WorldClaw** and Meta **WorldGen** lead the agentic/procedural, engine-ready mesh worlds. For real-time interactive (video) worlds, Matrix-Game 4.0, HY-World 1.5 (WorldPlay) and Yume 1.5 are the open references. The closed frontier is World Labs' Marble (and Genie 3, covered elsewhere), which open systems benchmark against.

### Cited Findings
- HY-World 2.0 is "comparable to the closed-source model Marble" per Tencent. It is multimodal (text, image, multi-view, video) and outputs 3DGS, mesh and point cloud for Unity, UE and Isaac. — [NYU Shanghai RITS](https://rits.shanghai.nyu.edu/ai/tencent-open-sources-hy-world-2-0-a-multi-modal-3d-world-model/); [GitHub](https://github.com/Tencent-Hunyuan/HY-World-2.0)
- The HY-World 2.0 README argues that video world models are weaker in persistence, 3D consistency and controllability, which motivates its explicit-3D design. — [GitHub](https://github.com/Tencent-Hunyuan/HY-World-2.0)
- Lyra 2.0 targets the two main failure modes of long-horizon video-to-3D, spatial forgetting and temporal drift, and is released with weights (HF nvidia/Lyra-2.0) plus GUI and training code. — [arXiv 2604.13036](https://arxiv.org/abs/2604.13036); [GitHub](https://github.com/nv-tlabs/lyra)
- ABot-3DWorld 0 "sets the state of the art among open-source methods" and beats Marble on scene fidelity under rich multimodal inputs. This is the authors' own claim, and the experiments were not verified. — [arXiv 2607.11673](https://arxiv.org/html/2607.11673v2)
- FlashWorld generates 3DGS worlds in 5–10 s on one GPU and was an ICLR 2026 Oral. — [HunyuanWorld README](https://github.com/Tencent-Hunyuan/HunyuanWorld-1.0); [GitHub FlashWorld](https://github.com/imlixinyang/FlashWorld)
- Meta WorldGen (CVPR 2026) produces traversable, navmesh-aware, decomposed mesh worlds for game engines, but no code was found. WorldClaw (Aug 2026) scales agentic generation to large open worlds with editable instance-level assets, and its repo has 1.4k stars. — [arXiv 2511.16825](https://arxiv.org/abs/2511.16825v1); [arXiv 2608.05248](https://arxiv.org/abs/2608.05248); [GitHub WorldClaw](https://github.com/Tencent-Hunyuan/Hunyuan3D-WorldClaw)
- Matrix-Game 4.0 (Oct 2026) reaches 58–67 FPS at 864x480 on consumer RTX 50-series GPUs with an engine-plus-neural-renderer design. — [GitHub](https://github.com/SkyworkAI/Matrix-Game)
- Remaining limitations, as stated by repos: heavy hardware (HY-Pano 2.0 is about 80B and WorldStereo 2.0 about 17B; Yume needs at least 16 GB for inference and 16 A100s for training), restrictive community licenses (Tencent), limited scene coverage (Matrix-Game 4.0 has three scenes), an unresolved license (WorldGrow) and experimental components (ZiYang-xie WorldGen). — [HY-World-2.0](https://github.com/Tencent-Hunyuan/HY-World-2.0); [YUME](https://github.com/stdstu12/YUME); [Matrix-Game](https://github.com/SkyworkAI/Matrix-Game); [WorldGrow](https://github.com/world-grow/WorldGrow); [WorldGen](https://github.com/ZiYang-xie/WorldGen); [The Neuron on Hunyuan license](https://www.theneuron.ai/explainer-articles/tencent-just-open-sourced-a-3d-world-generator)

### Inferences
- SOTA has shifted from "optimize one scene per prompt" (minutes to hours, small extent) to "generate a panorama or video, then reconstruct feed-forward", which gives large and navigable but still mostly static worlds.
- The open questions are unbounded scale with persistence, dynamics and interactivity in explicit 3D (WonderPlay and CityDreamer4D are early steps), and making both licensing and hardware accessible.
- Likely gap to the closed frontier: Tencent and ABot claim parity with Marble, but no independent benchmark was found. Treat "Marble-level" as a vendor claim.

### Gaps
- No independent, cross-method benchmark of 2026 world generators was found (each paper uses its own metrics, and WorldScore-type benchmarks were not investigated).
- HY World 2.1's improvements and any October 2026 HY-World or Lyra updates were not found.
- Whether ABot-3DWorld 0 and Meta WorldGen code is public remains unverified.
